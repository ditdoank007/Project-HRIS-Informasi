Target:
- CT ID: 134
- Hostname: HRIS-INFORMASI

Initial deployment flow:

1. Prepare CT134.
2. Clone GitHub repository.
3. Create production environment file outside Git.
4. Install runtime dependencies.
5. Configure service/reverse proxy.
6. Verify internal DNS and HRIS Reborn API connectivity.
7. Enable production service.
